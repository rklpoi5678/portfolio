# portfolio — Kim Yoon-gi (김윤기)

Full-stack developer portfolio built with Next.js 15, React 19, TypeScript.

## Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript 5.8
- **Styling:** Tailwind CSS 3.4 + shadcn/ui
- **Animations:** GSAP 3.12 (ScrollTrigger), Framer Motion 12, SplitType
- **Scroll:** Lenis smooth scroll
- **Fonts:** Inter, JetBrains Mono

## Features

- Bilingual (Korean/English) support via React Context
- Dark-first design with indigo/cyan accent palette
- Smooth scroll with GSAP ScrollTrigger integration
- Text reveal animations + staggered children
- 7 portfolio projects with detail pages
- Static generation (SSG)

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
pnpm build
```

## Deploy

Deployed via Vercel.
